06. Usage rules

A handoff checklist to help another designer or developer apply the system.

  • Spacing scale: 4, 8, 12, 16, 20, 24 and 32px.
  • Corner radii: 6px for controls, 10px for cards, 12px for key surfaces.
  • Minimum target height for prominent buttons: 43px.
  • Always show a visible focus indicator and a text label for inputs.
  • Never communicate errors by colour alone; pair colour with clear text.
  • Use Figma component variants for default, hover, focus, error, and disabled states.

See the Figma handoff specification for component naming and frame structure.
