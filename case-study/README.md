# Task 4 · End-to-end UX case study

Open **[the 10-slide interactive deck](./index.html)**. It is designed for direct browser review and can be exported to PDF with the browser's Print → Save as PDF feature.

**Keyboard:** Arrow Left / Right, Page Up / Down, Home / End. Slides are responsive and the print CSS reveals all ten slides rather than printing only the active one.

## What it documents

1. Scope and design goal for a local-first money journal.
2. Usability and trust hypotheses (explicitly not field research).
3. Intentional product boundaries.
4. Illustrated first-use task journey.
5. Information architecture and entry flow.
6. Mobile visual hierarchy.
7. Reusable design tokens and Figma library.
8. Interaction and correction rationale.
9. Automated QA evidence and open risks.
10. Outcome, links and future validation.

The deck is original coursework. No user interviews, business metrics, production usage, bank integrations or real payments are fabricated. The live wallet and checkout prototypes, GitHub checks and native Figma designs are linked from slide ten.
